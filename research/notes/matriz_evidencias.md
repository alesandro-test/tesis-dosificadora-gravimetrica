# Matriz de evidencias

## Propósito

Vincular cada afirmación relevante del proyecto con una fuente real o con datos identificables. La matriz comienza con los elementos necesarios para definir el proyecto; no constituye todavía una revisión de literatura ni contiene resultados.

## Estados

| Estado | Criterio |
|---|---|
| `Faltante` | La evidencia aún no fue identificada. |
| `Localizada` | Existe una fuente o conjunto de datos candidato, pendiente de revisión. |
| `Verificada` | La evidencia fue consultada y su ubicación exacta quedó registrada. |
| `Incorporada` | La evidencia verificada ya respalda una afirmación en un entregable. |
| `Descartada` | No es pertinente, confiable o utilizable; se registra el motivo. |

## Controles antes de usar una evidencia

- [ ] La fuente o el dato existe y puede recuperarse.
- [ ] Autoría, fecha y versión están identificadas.
- [ ] La ubicación exacta del respaldo está registrada.
- [ ] La evidencia sustenta la afirmación concreta, no solo el tema general.
- [ ] Se documentaron limitaciones, supuestos o posibles sesgos.
- [ ] Si contiene datos sensibles o restringidos, se definió un manejo adecuado antes de versionarlos.
