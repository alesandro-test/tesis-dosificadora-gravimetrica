# Dosificadora gravimétrica de ingredientes secos

Proyecto de Taller de Grado de Ingeniería Mecatrónica.

Caso de estudio:

**Panadería San Miguel — Santa Cruz de la Sierra, Bolivia.**

## Estructura

- `docs/thesis/`: documento oficial en LaTeX.
- `context/`: contexto operativo para agentes de IA.
- `research/`: evidencia, observaciones docentes y referencias.
- `docs/design/Casa_de_calidad_San_Miguel_revision.xlsx`: casa de calidad vigente.
- `archive/`: versiones sustituidas y recursos sin uso activo, organizados por su ruta de origen. Ver [índice del archivo](archive/README.md).
- `AGENTS.md`: instrucciones para agentes de trabajo.
- `CLAUDE.md`: instrucciones para Claude Code.

## Contexto del proyecto

Comenzar por:

1. `context/PROJECT_CONTEXT.md`
2. `context/STATUS.md`

El documento principal es `docs/thesis/main.tex`; su propuesta activa está en
`docs/thesis/chapters/marcopractico/propuesta.tex`. Las versiones antiguas no
deben utilizarse como fuente vigente. Los archivos auxiliares de compilación
se regeneran; los datos originales y antecedentes se conservan.

Para información adicional:

- `context/PROFESSOR_NOTES.md`
- `context/THESIS_STRUCTURE.md`
- `context/DECISIONS.md`

## Regla

Los datos experimentales detallados se encuentran en:

`research/notes/contexto_tesis_san_miguel.md`

No inventar datos o parámetros todavía no definidos.
